Ejemplo 1: Nivel Básico (Flujo Lineal de Autenticación)

Contexto Backend: Este flujo representa la validación inicial de seguridad que ocurre en cualquier API REST cuando un cliente intenta acceder a un recurso protegido utilizando un token JWT o de sesión. El backend actúa como un nodo decisor (rombo) que evalúa la integridad del token: si es correcto permite el acceso, de lo contrario rechaza la petición con un código HTTP 401.

Código con comentarios paso a paso:
