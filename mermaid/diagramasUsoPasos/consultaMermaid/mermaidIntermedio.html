Ejemplo 2: Nivel Intermedio (Arquitectura y Subgráficos)

Contexto Backend: En una arquitectura de microservicios moderna, las aplicaciones se dividen por responsabilidades en capas físicas o lógicas. Este diagrama modela un sistema distribuido donde un API Gateway centraliza el tráfico entrante y lo distribuye hacia servicios especializados (Autenticación, Usuarios), los cuales se conectan a bases de datos y caches independientes (PostgreSQL, Redis).

Código con comentarios paso a paso:

<pre class="mermaid">
graph TB
    %% PASO 1: Creación de subgráficos para segmentar capas de infraestructura
    subgraph Capa de Entrada
        Client[Cliente Web / Móvil] --> Gateway[API Gateway / Load Balancer]
    end

    subgraph Capa de Lógica Backend
        Gateway --> AuthSrv[Servicio de Autenticación]
        Gateway --> UserSrv[Servicio de Usuarios]
    end

    subgraph Capa de Persistencia
        AuthSrv --> Redis[(Redis Cache)]
        UserSrv --> Postgres[(PostgreSQL DB)]
    end

    %% PASO 2: Inyección de estilos de color personalizados para nodos clave
    style Gateway fill:#f9f,stroke:#333,stroke-width:2px
    style Postgres fill:#bbf,stroke:#333,stroke-width:1px
</pre>
